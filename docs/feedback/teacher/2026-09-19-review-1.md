## Discussed

**Who takes the register.** The class teacher always: the "Take register" action on Today shows only for the classes they lead, and the office's Teacher column already names the class teacher. Any teacher of the class (and the office) can still open a register and fill it in or correct it — the fallback when the class teacher is away — so nothing is lost on a sick day.

**Breadcrumbs.** Rule from now on (DESIGN §3.2): the trail follows the URL — the pages above this one — and a page reached from somewhere else gets a *related* link in the header ("Level 4's attendance") instead of a borrowed trail. Only the register pages broke the rule, so no restructuring was needed.

**Draft attachments.** With attachments now added before publishing, a file on a draft used to be visible to the class already (and announced). Attachments to unpublished homework are staff-only until it is published, and the homework's own announcement covers them.
